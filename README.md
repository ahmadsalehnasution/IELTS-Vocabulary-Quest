# IELTS Vocabulary Quest

IELTS preparation RPG — 19,822 questions and 2,840 flashcards in one self-contained page, playable offline.

**Play it:** https://<your-username>.github.io/IELTS-Vocabulary-Quest/

## Install on iPhone
1. Open the link above in **Safari**.
2. Tap **Share → Add to Home Screen → Add**.
3. It opens full-screen and keeps working with no signal after the first load.

## What is in this repository
- `index.html` — the whole game (questions, flashcards, styling, sounds, icon). No build step.
- `sw.js` — service worker that caches the app for offline play.
- `manifest.webmanifest` + `icon-*.png` — makes it installable to the home screen.
- `.nojekyll` — tells GitHub Pages to serve the files verbatim.

Deployed from the repaired build (progress saving, spaced repetition, Listening read-aloud, corrected source labels).
